# Notas para Contrato de Fornecimento do Sistema PDV

## Cláusula — Acesso aos Dados pelo Fornecedor (LGPD)

> *"O fornecedor poderá acessar os dados do sistema para fins exclusivos de suporte técnico, manutenção, diagnóstico de falhas e acompanhamento operacional, mantendo sigilo e não compartilhando informações entre clientes."*

**Base legal:** LGPD — Lei 13.709/2018, art. 7º, incisos II (execução de contrato) e IX (legítimo interesse).

**Condições para licitude:**
- Informar no contrato/termos de uso que o acesso existe
- Limitar o acesso ao necessário para a finalidade declarada
- Não compartilhar dados de um cliente com outro
- Não usar dados dos clientes para fins comerciais próprios sem consentimento
- Manter registros (log de auditoria) de acessos realizados
